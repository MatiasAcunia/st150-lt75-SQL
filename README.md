# Striver 150 · Blind 75 · SQL

Personal practice repository with my own Java solutions to algorithmic problems and my own SQL queries.

## Organization

- `striver-150/` — Java solutions, following the Striver 150 sheet.
- `blind-75/` — Java solutions, following the Blind 75 sheet.
- `sql/` — SQL practice problems.

Each algorithm problem has its own folder, named `001-problem-slug/`, containing `Solution.java`. Each SQL problem can be a single `001-problem-slug.sql` file. The number represents its position in **my** practice order, not the problem's platform ID.

Example:

```text
striver-150/
  001-two-sum/
    Solution.java
blind-75/
  001-valid-parentheses/
    Solution.java
sql/
  001-second-highest-salary.sql
```

## How I work

1. Read the original problem and its constraints.
2. Design and implement my own solution in Java or SQL.
3. Check edge cases and, for Java, time/space complexity.
4. Save the accepted solution under the corresponding track.

A problem may appear in more than one sheet. Re-solving it independently is useful for practice; it is not necessarily a new unique problem.

Problem statements belong to their original platforms; this repository contains my own implementations, not copied statements or editorial solutions.

My separate Java data-structures library is a different project from this collection of practice solutions.
