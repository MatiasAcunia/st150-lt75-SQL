# Algoritmos, estructuras de datos y SQL

Repositorio de práctica con soluciones en Java y consultas SQL.

## Colecciones

- [Striver 150](striver-150/): 150 ejercicios de estructuras de datos y algoritmos.
- [Blind 75](blind-75/): 75 ejercicios de estructuras de datos y algoritmos.
- [SQL Practice Set](sql/): 225 ejercicios de SQL.

Los ejercicios están organizados en archivos individuales con enlaces a los enunciados originales. Las colecciones de Java pueden contener problemas en común.

## Ruta activa reducida (noviembre de 2026)

La ruta de estudio acordada es **75 ejercicios DSA únicos + 75 ejercicios SQL**. Las clases 10–14 se mantienen y la selección evita repetir ejercicios comunes entre Striver y Blind.

- [Lista curada y seguimiento: 75 DSA + 75 SQL](RUTA_CURADA_75_DSA_75_SQL.md)

Las tres colecciones completas siguen disponibles como referencia, pero **no constituyen trabajo pendiente**. La selección curada es la autoridad para la ruta activa.
